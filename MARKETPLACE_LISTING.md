## Short description

Import and submit University of Maryland CS course projects from JetBrains IDEs using the current CAS/browser verification workflow.

## Full description

UMD CS Submit Client adds project-import and project-submission actions for University of Maryland computer science course projects. It supports the current browser/CAS verification workflow used by the UMD CS Submit Server and can import the Eclipse-style starter-project ZIPs distributed by supported courses.

The plugin does not include analytics or telemetry. It is an independent open-source project and is not affiliated with or endorsed by the University of Maryland. It is based on the original UMD CS Project Integration plugin by Atheesh Thirumalairajan and is maintained by Taha Cheji.

## Before clicking Submit on Marketplace

Replace/fill these account-specific fields in the Marketplace form:

- **Source code URL:** your public GitHub repository URL
- **Issue tracker:** your repository's Issues URL
- **Privacy policy:** link to `PRIVACY.md` in the public repository
- **Vendor website:** a valid website or public developer profile
- **Vendor email:** a valid support/contact email
- **Trader status:** complete the Marketplace vendor-profile declaration

Do not publish until the repository is public, because an open-source Marketplace plugin needs a working source-code link.
